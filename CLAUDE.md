## Project Overview

MaterialBox is a local-first browser extension (Chrome/Firefox) for collecting, classifying, and managing web media (images/videos). It stores data in IndexedDB with optional cloud sync and uses TensorFlow.js + local models for AI-based categorization.

## Build Commands

```bash
npm install          # Install dependencies (Node.js 18+, npm 9+)
npm run build        # Full build: AI bundle + Export bundle + Browser packages
npm run build:ai     # Build AI bundle (ai-entry.js → ai.bundle.js)
npm run build:export # Build Export bundle (export-entry.js → export.bundle.js)
npm run build:packages # Copy src + locales + node_modules to dist/{chrome,firefox}
```

**Note**: After modifying `src/lib/ai-entry.js` or `src/lib/export-entry.js`, always run `npm run build`.

## Architecture

```
src/
├── background.js              # Service worker entry - context menus, message routing
├── background/
│   ├── message-router.js     # Routes messages to handlers by type
│   └── handlers/
│       ├── capture-handler.js  # Captures active tab media, context menu saves
│       ├── library-handler.js  # Delete, export, category updates
│       ├── sync-handler.js    # Cloud sync upload/download
│       └── stats-handler.js   # Statistics, AI status
├── lib/
│   ├── db.js                # IndexedDB operations (media + meta stores)
│   ├── classifier.js        # Rule-based + learned categorization
│   ├── ai-entry.js          # TensorFlow.js/MediaPipe AI integration (bundled)
│   ├── export-entry.js      # Export logic (bundled)
│   ├── sync.js              # Cloud sync implementation
│   ├── i18n.js              # Internationalization
│   └── utils.js             # Common utilities, extension API wrapper
├── pages/
│   ├── popup.js/.css/.html  # Quick save popup
│   └── dashboard.js/.css/.html # Material library management UI
└── content-script.js        # Page media scanning and extraction
```

## Key Patterns

**Message Routing**: Background uses a typed message system (e.g., `GET_STATS`, `CAPTURE_ACTIVE_TAB_MEDIA`). Handlers are in `src/background/handlers/`. See `message-router.js` for the routing table.

**IndexedDB Stores**:
- `media` - stores media items with indexes: `createdAt`, `category`, `type`, `sourceUrl`, `contentHash`
- `meta` - key-value store for settings, tags, sync state

**DB Functions**: `putMedia()`, `getMedia()`, `getAllMedia()`, `deleteMedia()`, `getMeta()`, `putMeta()` in `db.js`.

**Context Menus**: Created in `background.js` on install/startup for image/video right-click save.

**Bundled Assets**: `src/generated/ai.bundle.js` and `src/generated/export.bundle.js` are generated by esbuild and should be regenerated after editing the source entry points.

## Browser Extension Loading

- **Chrome**: Load unpacked from project root (uses `manifest.json`)
- **Firefox**: Load `dist/firefox/manifest.json` after build, or use "Temporary load" from `about:debugging`

## CI/Release

GitHub Actions (`.github/workflows/release.yml`) builds on push to main and tags starting with `v`. It creates zip artifacts for Chrome and Firefox, and auto-generates release notes from CHANGELOG.md.
