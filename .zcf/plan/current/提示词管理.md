# 提示词管理功能 - 执行计划

## 任务概述
在 MaterialBox dashboard 中新增 Prompts Tab，提供 AI 提示词的收藏、管理功能。

## 需求背景
用户需要快捷保存遇到的好用 AI 提示词，目前没有集中管理的地方。

## 数据结构
```js
{
  id: string,           // crypto.randomUUID()
  title: string,        // 标题（可选，默认取前20字符）
  content: string,      // 提示词内容
  sourceUrl: string,    // 来源页面 URL
  tags: string[],       // 关联 tag id 列表
  createdAt: number,    // 创建时间戳
  updatedAt: number     // 更新时间戳
}
```

## 执行步骤

### 步骤 1：数据库升级
- 文件：`src/lib/db.js`
- 操作：
  - `DB_VERSION` 从 2 升级到 3
  - `onupgradeneeded` 中新增 `prompts` 对象仓库（keyPath: `id`）
  - 新增函数：`putPrompt`, `getPrompt`, `getAllPrompts`, `deletePrompt`, `updatePrompt`

### 步骤 2：消息处理器
- 文件：`src/background/handlers/prompts-handler.js`（新建）
- 消息类型：`SAVE_PROMPT`, `GET_PROMPTS`, `DELETE_PROMPT`, `UPDATE_PROMPT`

### 步骤 3：路由注册
- 文件：`src/background/message-router.js`
- 操作：添加 `SAVE_PROMPT`, `GET_PROMPTS`, `DELETE_PROMPT`, `UPDATE_PROMPT` 路由

### 步骤 4：右键菜单
- 文件：`src/background.js`
- 操作：新增 context menu item `save-to-prompts`

### 步骤 5：国际化
- 文件：`src/lib/i18n.js`
- 新增词条：`promptsTab`, `savePrompt`, `promptTitle`, `promptContent`, `promptSource`, `noPrompts`, `promptSaved`, `promptDeleted`, `promptCopied`

### 步骤 6：Dashboard UI
- 文件：`src/pages/dashboard.html`
- 操作：新增 Prompts Tab 按钮

### 步骤 7-11：Dashboard JS
- 文件：`src/pages/dashboard.js`
- 操作：
  - Tab 切换逻辑（mediaType === "prompts"）
  - Prompts 列表渲染（卡片展示）
  - 快捷键 P 呼出快速保存对话框
  - 快捷键注册
